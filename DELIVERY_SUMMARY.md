## Known Limitations & Notes

1. **No Payment Integration**: Accepts orders but doesn't process payments
   - Can add Stripe/other payment gateway

2. **Product Images**: Uses Firebase Storage paths
   - Admin needs to upload images via Firebase Console or implement UI

3. **Email Notifications**: Contact form saves but doesn't send emails
   - Can add Firebase Functions or SendGrid

4. **Shipping Calculation**: "To be calculated" on checkout
   - Can be implemented with business logic

5. **Product Variants**: Not implemented
   - Can be added if needed (colors, sizes)
